# ProTradeJournal Desktop

Windows installers for the ProTradeJournal desktop app. This repository holds the releases only; the app's source code isn't published here.

**Get the app from [protradejournal.in/download](https://www.protradejournal.in/download)**, which also lists what it does and what it needs.

- The app runs on Windows 10 and 11 (64-bit).
- It needs a ProTradeJournal account with desktop access. It checks your access when it starts, so installing it on its own doesn't unlock anything.
- To update an installed copy, open **Settings → Check for Updates** in the app. It downloads new versions from this repository's releases.

For help, use **Support** inside [ProTradeJournal](https://www.protradejournal.in).
